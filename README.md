# RankLab

An app designed to rank elements of any kind.

---

## Overview

RankLab is a project based on rankings. The user will be able to use existing rankings, define their own criteria, place elements into different tiers, and more.

The goal is not only to freely rank elements related to any topic, but also to explain and justify the decisions behind those rankings.

## Product Vision

In the long term, the goal of this product is to allow users to create rankings, save them, share them, and view other users' rankings.

The page will have its own rankings, but users will also be able to create templates for other users to use.

Both templates and rankings could be saved by any user.

## Problem Statement

Users will have a powerful tool to rank, justify, and share their thoughts.

RankLab is meant to become a place where people can share and debate their appreciation of different elements from any topic.

## Target Users

### Primary User

Enthusiastic people with defined hobbies and the desire to share their thoughts and preferences.

### Secondary Users

Content creators who want to show their ranking process.

## Value Proposition

This product's strengths will be its ease of use, customization, and community interactions.

## Core User Journey

```text
Explore existing templates
Rank based on personal criteria
Save and share the ranking
Create custom templates
View, save, share, and comment on other users' rankings
```

---

## Navigation Flow

The MVP has a simple navigation flow:

```text
Home
→ Select a template
→ Rank the template elements
→ Reset the ranking if needed
→ Return to Home by clicking the RankLab logo

## MVP Scope

### Ranking Management

- Three existing templates.
- Ten elements for each topic.
- Five tiers by default.
- The user will be able to place the elements into the tiers as they want.

### Tier Management

- Tier color and name can be changed.
- Any number of elements can be placed in each tier.

### Item Management

- Items will be previously created.
- At first, items cannot be added or removed.
- Items can be placed in any tier.
- Items can be moved from one tier to another at any time.

### Application Behavior

- The user will first see the home page with the title and description.
- Existing templates will be shown below and can be selected.
- After selecting a template, the user will go to the template page.
- The user can rank the items.

---

## Non-Goals

- Custom templates.
- User creation.
- Ranking storage.
- Adding or removing elements.
- Any kind of interaction with other users.

---

## Product Differentiation

This product allows users not only to create rankings, but also to justify and explain their choices.

### Community Features

- Create custom templates.
- Use other users' templates.
- See, share, and comment on other users' rankings.
```
